# CivAsunder

CivAsunder - Paper-плагин для приватного цивилизационного Minecraft-сервера. Он добавляет государства, ратуши и укрепления, регенерирующие рудные жилы, материю как серверную валюту, систему душ после смерти, измененную боевку и набор специальных стрел.

## Требования

- Paper API `1.21`
- Java `25`
- Maven `3.9+`

## Сборка

```bash
mvn clean package
```

Готовый плагин будет собран в:

```text
target/CivAsunder-1.0.0-java25.jar
```

## Установка

1. Соберите jar или возьмите готовый артефакт из `target/`.
2. Положите `CivAsunder-1.0.0-java25.jar` в папку `plugins` Paper-сервера.
3. Запустите или перезапустите сервер.
4. Настройте белый список CivAsunder через `/civwl`.

Плагин хранит данные в своей папке внутри `plugins/CivAsunder/`.

## Основные системы

### Государства

Государство создается через Блок Сердца Государства. Игрок ставит блок, затем выполняет:

```text
/k create <название>
```

Король получает уровень близости `100`. Участники могут получать уровни `1-100`; игроки с уровнем выше `1` могут приглашать и управлять участниками ниже своего уровня.

Команды:

| Команда | Описание |
| --- | --- |
| `/k help` | справка по системе государств |
| `/k create <название>` | создать государство после установки Блока Сердца |
| `/k invite <ник>` | пригласить игрока |
| `/k accept` | принять приглашение |
| `/k kick <ник>` | исключить участника с меньшим уровнем |
| `/k rank <ник> <1-100>` | изменить уровень участника |
| `/k transfer <ник>` | передать корону онлайн-участнику |
| `/k leave <название>` | покинуть государство |
| `/k list` | список государств |
| `/k info <название>` | участники и уровни государства |

Рецепт Блока Сердца Государства:

```text
Золото | Золото             | Золото
Золото | Стол лучника       | Золото
Золото | Золото             | Золото
```

### Ратуши и укрепления

Ратуша защищает территорию вокруг себя. Базовый радиус защиты - `16` блоков, энергия ратуши увеличивает радиус. В защищенной зоне чужие игроки не могут свободно ломать и ставить блоки.

Рецепт Блока Ратуши:

```text
Золото | Золото             | Золото
Золото | Стол лучника       | Эссенция материи
Золото | Золото             | Золото
```

Укрепляемые блоки получают прочность и теряют ее от разрушения или взрывов. Нельзя укреплять обсидиан, плачущий обсидиан, бедрок, руды и стратегические ресурсные блоки.

### Рудные жилы

Плагин заменяет обычную генерацию руды собственной системой жил. Поддерживаются:

- уголь
- железо
- золото
- алмазы

При добыче блок жилы исчезает и восстанавливается позже. Частая добыча одного и того же блока повышает усталость жилы и увеличивает время восстановления.

Команды администратора:

| Команда | Описание |
| --- | --- |
| `/vein populate` | создать случайную жилу в текущем чанке |
| `/vein locate` | найти ближайшую активную жилу в радиусе поиска |

### Компас поиска руд

Кастомный компас указывает на ближайшую активную рудную жилу. Радиус поиска - `12` чанков, кулдаун сканирования - `10` секунд.

Рецепт:

```text
Каменная кирка | Камень             | Каменная кирка
Камень         | Эссенция материи   | Камень
Каменная кирка | Камень             | Каменная кирка
```

В центре рецепта должна быть именно кастомная Эссенция материи.

### Материя

Материя - внутренняя валюта в виде кастомного осколка аметиста. Ее можно получать переработкой ресурсов через Конвертер материи или командой `/convert` для операторов.

Рецепт Конвертера материи:

```text
Пусто          | Гладкий камень     | Пусто
Гладкий камень | Верстак            | Гладкий камень
Пусто          | Гладкий камень     | Пусто
```

Конвертер открывается ПКМ по установленному блоку. Входной слот принимает ресурсы, выходной слот выдает Эссенцию материи.

### Души и Чистилище

После смерти игрока создается предмет души в виде тотема бессмертия, а сам игрок попадает в мир `civ_souls`. Базовое время заключения - `5` минут.

Душу можно освободить правым кликом по предмету души. Если предмет души уничтожен, деспавнится или сгорает после задержки, игрок также освобождается.

Алтарь Заточения Душ позволяет продлевать заключение, расходуя Эссенцию материи. Стоимость каждого следующего продления растет по степени двойки.

Рецепт Алтаря:

```text
4x Эссенция материи | 4x Эссенция материи | 4x Эссенция материи
4x Эссенция материи | Обсидиан            | 4x Эссенция материи
4x Эссенция материи | 4x Эссенция материи | 4x Эссенция материи
```

Shift-крафт алтаря запрещен, чтобы не ломать расход матрицы.

Команда оператора:

| Команда | Описание |
| --- | --- |
| `/escape` | досрочно вывести себя из Чистилища и удалить связанные предметы души |

### Боевка

Плагин меняет блокирование оружием и щитом:

- мечи, топоры и щит могут использоваться для блока;
- блок снижает входящий урон, если защитник смотрит на атакующего;
- блок копит усталость рук;
- при `100%` усталости щит/блок пробивается на `5` секунд;
- после удачного блока защитник получает короткое окно контратаки;
- атаки во время собственного блока отменяются.

Дополнительно:

- фейерверки не дают ускорение на элитрах;
- трейды жителей фиксируются при первом получении профессии/уровня, что мешает бесконечно роллить сделки;
- железный голем от паники появляется только если рядом достаточно напуганных жителей.

### Специальные стрелы

Все специальные стрелы создаются обычным крафтом и помечаются через persistent data, поэтому механика срабатывает только у предметов CivAsunder.

| Стрела | Рецепт | Эффект |
| --- | --- | --- |
| Взрывающаяся | `стрела + TNT` | при попадании создает TNT; блоки ломаются с силой `4.0`, урон игрокам снижен как у силы `0.7` |
| Пробивающая | 3 стрелы вертикально и железный топор справа от центральной стрелы | крафтит `3` стрелы, наносит чистый урон и отключает поднятый щит на `5` секунд |
| Стрела оплавления | `стрела + огниво` | повреждает броню или поднятый щит вместо здоровья |
| Телепортирующая | `стрела + эндер-жемчуг` | телепортирует стрелка в точку попадания |
| Отскакивающая | `стрела + слизневый блок` | рикошетит до `5` раз, теряя урон после каждого отскока |

Рецепт пробивающей стрелы:

```text
Пусто | Стрела | Пусто
Пусто | Стрела | Железный топор
Пусто | Стрела | Пусто
```

## Авторизация и белый список

CivAsunder ведет собственный белый список и простую авторизацию игроков. До входа игрок переносится в `civ_souls`, его инвентарь кешируется, чат и большинство команд блокируются.

Команды:

| Команда | Право | Описание |
| --- | --- | --- |
| `/register <пароль> <повтор>` | `civ_asunder.user` | регистрация |
| `/login <пароль>` | `civ_asunder.user` | вход |
| `/logout` | `civ_asunder.user` | выйти из аккаунта |
| `/civwl add <ник>` | operator | добавить игрока в белый список CivAsunder |
| `/civwl remove <ник>` | operator | удалить игрока из белого списка CivAsunder |

## Права

| Permission | По умолчанию | Назначение |
| --- | --- | --- |
| `civ_asunder.user` | все игроки | регистрация, вход, выход |
| `civ_asunder.admin` | operator | команды администрирования жил и конвертации |
| `civ_asunder.escape` | operator | досрочный выход из Чистилища |

## Данные

Плагин сохраняет состояние асинхронно в файлы внутри папки данных:

- `kingdoms_data.txt` - государства, участники и блоки сердец;
- `townhalls.yml` - ратуши и укрепленные блоки;
- `matter.yml` - установленные конвертеры материи;
- `souls.yml` - заключенные души;
- `veins_timers.txt` - таймеры восстановления жил;
- `veins_fatigue.txt` - усталость жил.
